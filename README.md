# markdown-viewer

## 무엇을 하는가

로컬 폴더에 쌓인 문서를 빠르게 찾아 읽는 Windows 데스크톱 뷰어다.

루트 폴더 하나를 열면 왼쪽 탐색기에 그 아래의 문서·텍스트·코드 파일이 트리로
보인다. 파일을 고르면 탭으로 열리고, 마크다운은 GitHub Flavored Markdown으로
렌더링되며 텍스트와 코드는 줄 번호와 문법 강조가 붙은 읽기 전용 뷰어로 보인다.
여러 문서를 탭으로 띄워 두고 넘나들며 읽고, 보기 영역을 좌우로 갈라 두 문서를
나란히 놓을 수 있다.

문서 안의 참조를 따라간다. 상대경로로 참조한 루트 안의 이미지는 문서와 함께
보이고, 다른 문서로의 상대경로 링크는 앱 안에서 열린다. 외부 URL만 기본 브라우저로
넘긴다.

**읽기 전용 뷰어다.** 원본 파일을 고치지 않고, 인터넷 없이 동작하며, 사용자가 고른
루트 폴더 밖으로 나가지 않는다.

창·탐색기·탭·좌우 가르기·테마 같은 껍데기는 `tab-explorer-templates`를 복사해
쓴다. 이 프로젝트가 만드는 것은 트리에 무엇을 보여줄지, 행을 고르면 무엇이 열릴지,
탭 안에 무엇이 그려질지 — 즉 문서를 읽는 부분이다.

## 무엇을 하지 않는가

- **편집기가 아니다.** 문서를 고치거나 만들거나 지우지 않는다.
- **범용 파일 관리자가 아니다.** 파일 복사·이동·이름 변경, git, 터미널 실행을 담지
  않는다.
- **문서 창고가 아니다.** 색인을 만들거나 전문 검색을 하지 않으며, 폴더를 열 때 파일을
  미리 훑지 않는다. 고른 파일 하나만 그때 읽는다.
- **범용 뷰어가 아니다.** 정해 둔 확장자만 열고, 그 밖의 파일은 탐색기에 표시하지
  않는다.
- **모바일과 클라우드를 다루지 않는다.** Windows 로컬 실행이 1차 대상이다.

## 문서

- 현재 버전 작업 문서: `docs/current/` (BRIEF, DECISIONS, SPEC, PLAN, PROGRESS)

## 어떻게 쓰는가

### 1. 실행 환경
- Windows 10 이상
- Node.js v18 이상

### 2. 설치 및 실행

저장소를 받은 뒤 `host_electron` 디렉토리에서 의존성을 설치하고 앱을 실행합니다.

```powershell
cd host_electron
npm install
npm start
```

### 3. 주요 사용 방법
- **폴더 열기**: 메뉴의 `File > Open Folder...` 또는 `Ctrl+O`로 마크다운 문서가 있는 루트 폴더를 선택합니다.
- **문서 열기**: 왼쪽 탐색기 트리에서 파일을 클릭하면 새 탭으로 열립니다.
  - `.md` 파일: GitHub Flavored Markdown으로 서식 렌더링 (표, 체크박스, 코드펜스 등)
  - 코드/텍스트 파일: 줄 번호 및 9개 언어 문법 강조가 적용된 읽기 전용 뷰어
- **글꼴 크기 조절**: 읽기 영역에서 `Ctrl` + `+`/`=`, `Ctrl` + `-`, `Ctrl` + 휠로 50%~250% 확대/축소, `Ctrl` + `0`으로 기본 크기 복귀
- **코드 복사**: 코드 블록 상단 오른쪽의 "복사" 버튼을 누르면 원문 코드가 클립보드에 복사됩니다.
- **편집기 분할**: `File > Split Editor` 또는 `Ctrl+\`로 화면을 좌우로 분할하여 두 문서를 나란히 열람할 수 있습니다.
- **테마 전환**: 세로 띠 하단의 테마 버튼을 눌러 White, Gray, Dark 테마를 순환 전환합니다.

### 4. 주요 단축키
| 단축키 | 기능 |
| --- | --- |
| `Ctrl+O` | 루트 폴더 열기 |
| `Ctrl+W` | 활성 탭 닫기 |
| `Ctrl+B` | 탐색기 사이드바 접기/펼치기 |
| `Ctrl+\` | 편집기 좌우 가르기 |
| `F6` | 반대편 조각으로 탭 이동 |
| `F5` | 탐색기 새로고침 |
| `F11` | 집중(Zen) 모드 전환 |
| `Ctrl` + `+`/`-`/`0`/휠 | 읽기 영역 글꼴 크기 확대/축소/초기화 |
