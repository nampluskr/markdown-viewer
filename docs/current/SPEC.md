# SPEC — markdown-viewer

> 버전: v0.1 · 작성일: 2026-09-07
>
> 이 문서는 이번 버전이 만족해야 할 것을 담는다. 설계 결정의 근거는 `DECISIONS.md`,
> 구현 순서는 `PLAN.md`와 `backlog.json`이 담는다.

이 앱은 `tab-explorer-templates` v0.1의 껍데기를 복사해 쓴다(D-2). 창·탐색기 트리·
탭·좌우 가르기·메뉴 줄·상태 표시줄·테마·집중 보기·루트 경계·설정 보존·브릿지 계약과
오류 계약은 껍데기가 이미 충족하는 것이므로 아래 요구사항에 다시 적지 않는다. 여기
적는 것은 **이 앱이 갈아끼우는 자리 안에서 새로 만드는 것**뿐이다.

---

## 1. 기능 요구사항

### FR-1. 트리에 표시할 항목을 확장자로 거른다

* 내용: 트리 항목 자리에서 아래 표의 확장자를 가진 파일만 표시한다. 폴더는 항상
  표시한다. 표에 없는 확장자(이미지 포함)는 트리에 나타나지 않는다. 확장자 비교는
  대소문자를 구분하지 않는다.

| 구분 | 확장자 |
| --- | --- |
| 마크다운 | `.md` |
| 텍스트 | `.txt`, `.log` |
| 코드 | `.py`, `.pyi`, `.cpp`, `.cc`, `.cxx`, `.h`, `.hpp`, `.ts`, `.tsx`, `.js`, `.jsx`, `.mjs`, `.cjs`, `.ps1`, `.psm1`, `.psd1`, `.sh`, `.bash` |
| 설정 | `.json`, `.jsonc`, `.yml`, `.yaml`, `.toml` |

* 판정 방법:
  * 위 확장자 파일과 이미지 파일(`.png` 등), 그 밖의 확장자 파일을 함께 둔 폴더를
    열어 표의 확장자만 보이는지 확인한다.
  * 대문자 확장자(`README.MD`)가 표시되는지 확인한다.
  * 껍데기 코드에 확장자 문자열이 나타나는 곳이 0건인지 확인한다.

### FR-2. 행을 고르면 확장자에 따라 문서 보기가 열린다

* 내용: 행 선택 매핑 자리에서 `.md`는 마크다운 보기로, 나머지 지원 확장자는 텍스트·
  코드 보기로 여는 대상을 돌려준다. 폴더 행은 탭을 열지 않는다.
* 판정 방법:
  * `.md` 파일과 `.py` 파일을 각각 골라 서로 다른 보기가 열리는지 확인한다.
  * 폴더 행을 골랐을 때 탭 수가 늘지 않는지 확인한다.
  * 보기 종류가 프리셋 안에서만 결정되고 껍데기 수정이 0줄인지 확인한다.

### FR-3. 마크다운을 GitHub Flavored Markdown으로 렌더링한다

* 내용: 문단·제목·목록·강조 같은 기본 요소에 더해 표, 체크박스 목록, 인용문, 코드
  펜스, 수평선, 인라인 코드, 각주 없는 링크를 렌더링한다.
* 판정 방법:
  * 위 요소를 모두 담은 시험 문서를 열어 각 요소가 해당 HTML 요소로 나타나는지
    확인한다(표는 표로, 체크박스는 체크박스로).
  * 렌더 실패 시 문서 자리에 오류 상태가 보이고 앱이 계속 도는지 확인한다.

### FR-4. 읽기 영역이 세 테마를 따른다

* 내용: 마크다운 본문·코드 블록·텍스트/코드 뷰어의 배경·글자·경계선 색을 껍데기의
  디자인 토큰과 테마 값으로 정한다. 문법 강조는 밝은 테마에서 GitHub Light 계열,
  어두운 테마에서 GitHub Dark 계열을 쓴다.
* 판정 방법:
  * 세 테마(`white` · `gray` · `dark`)를 차례로 골라 읽기 영역의 배경과 글자가 함께
    바뀌는지 확인한다.
  * 읽기 영역 스타일에서 토큰을 거치지 않고 색이 직접 적힌 곳이 0건인지 확인한다.
  * 테마 전환 뒤 본문 글자와 배경의 대비가 4.5:1 이상인지 확인한다.

### FR-5. 코드에 아홉 가지 문법 강조를 적용한다

* 내용: 마크다운 코드 블록과 코드 뷰어에서 Python · C++ · TypeScript · JavaScript ·
  JSON · PowerShell · YAML · TOML · Bash의 문법 강조를 적용한다. 언어를 알 수 없으면
  강조 없이 그대로 보여준다.
* 판정 방법:
  * 아홉 언어의 코드 블록을 담은 시험 문서에서 언어마다 토큰 색이 둘 이상 나타나는지
    확인한다.
  * 언어 표시가 없는 코드 펜스와 지원하지 않는 언어에서 오류 없이 원문이 보이는지
    확인한다.

### FR-6. 코드 블록과 코드 뷰어에 복사 버튼을 둔다

* 내용: 코드 블록마다, 그리고 코드 뷰어에 현재 내용을 클립보드로 복사하는 버튼을
  둔다. 복사 성공과 실패를 사용자가 알 수 있게 표시한다.
* 판정 방법:
  * 버튼을 눌러 클립보드 내용이 원문과 같은지 확인한다(줄바꿈 포함).
  * 클립보드 접근이 거부된 상황에서 실패 표시가 나오고 앱이 계속 도는지 확인한다.

### FR-7. 텍스트·코드 파일을 읽기 전용 뷰어로 연다

* 내용: 지원 확장자 중 `.md`가 아닌 파일을 줄 번호가 붙은 읽기 전용 뷰어로 연다.
  2MB를 넘는 파일은 열지 않고 사유를 표시한다. 널 바이트가 있으면 바이너리로 보고
  거절한다. UTF-8(BOM 포함) 외의 인코딩은 오류로 안내한다(D-8).
* 판정 방법:
  * 정상 파일에서 줄 번호가 원문 줄 수와 같은지 확인한다.
  * 2MB 초과 파일, 널 바이트를 담은 파일, UTF-16 파일을 각각 열어 셋이 서로 구분되는
    사유와 함께 거절되는지 확인한다.
  * 위 셋 중 어느 경우에도 앱이 멈추지 않고 다른 탭이 그대로 도는지 확인한다.

### FR-8. 문서 안의 상대경로 이미지를 표시한다

* 내용: 마크다운 문서가 상대경로로 참조한 루트 안의 이미지를 문서와 함께 표시한다.
  지원 형식은 `.png` · `.jpg` · `.jpeg` · `.gif` · `.webp` · `.svg`다. 대상이 없거나
  루트 밖을 가리키면 이미지 대신 대체 텍스트와 오류 상태를 보인다.
* 판정 방법:
  * 여섯 형식을 참조하는 시험 문서에서 여섯 개가 모두 보이는지 확인한다.
  * 없는 파일, 루트 밖(`..\` 이탈 · 절대경로)을 가리키는 참조가 각각 대체 텍스트와
    오류 상태로 나타나고 문서의 나머지는 그대로 보이는지 확인한다.
  * 이미지 읽기가 브릿지를 거치는지, 보기 코드가 파일시스템 API를 직접 부르는 곳이
    0건인지 확인한다.

### FR-9. 문서 안의 링크를 대상에 따라 나눠 연다

* 내용: 루트 안을 가리키는 상대경로 `.md` 링크는 앱 안에서 연다. 이미 열려 있으면
  그 탭으로 가고, 아니면 새 탭으로 연다. `http`/`https` 외부 URL은 기본 브라우저로
  연다. 루트 밖을 가리키는 상대경로 링크는 열지 않고 오류를 알린다.
* 판정 방법:
  * 열려 있지 않은 문서로의 링크가 새 탭을 열고, 이미 열린 문서로의 링크가 탭 수를
    늘리지 않고 그 탭을 활성화하는지 확인한다.
  * 외부 URL이 앱 안에서 열리지 않고 기본 브라우저로 넘어가는지 확인한다.
  * 루트 밖 링크가 거부되고 앱이 계속 도는지 확인한다.

### FR-10. 읽기 영역의 글꼴 크기를 조절한다

* 내용: 마크다운 본문·코드 블록·텍스트/코드 뷰어의 글꼴 크기를 `Ctrl` + `+`/`=`,
  `Ctrl` + `-`, `Ctrl` + 마우스 휠로 확대·축소하고 `Ctrl` + `0`으로 기본값으로
  되돌린다. 확대·축소 범위는 기본값의 50%~250%다. 탐색기·탭·메뉴 줄·상태 표시줄의
  글꼴 크기는 바뀌지 않는다.
* 판정 방법:
  * 네 조작으로 읽기 영역 글꼴 크기가 바뀌고 `Ctrl+0`이 기본값으로 되돌리는지
    확인한다.
  * 범위 밖으로는 더 커지거나 작아지지 않는지 확인한다.
  * 조작 전후로 탐색기·탭·메뉴 줄·상태 표시줄의 글꼴 크기가 같은지 확인한다.

### FR-11. 탭 수명 동안 읽던 자리를 유지한다

* 내용: 문서 보기는 껍데기의 보기 수명주기(mount · activate · deactivate · resize ·
  destroy)를 구현하고, 탭 수명 동안 스크롤 위치와 글꼴 크기를 유지한다. 탭을 닫을
  때만 폐기한다.
* 판정 방법:
  * 문서를 아래로 스크롤한 뒤 다른 탭으로 갔다 돌아왔을 때 같은 자리가 보이는지
    확인한다.
  * 탭을 반대쪽 조각으로 옮긴 뒤에도 스크롤 위치가 유지되고 문서를 다시 읽지 않는지
    확인한다.
  * 탭을 닫을 때 보기의 정리 절차가 불리는지 확인한다.

### FR-12. 원본을 고치지 않고, 렌더 결과를 정화한다

* 내용: 앱은 루트 안 파일을 읽기만 한다. 마크다운을 HTML로 만든 결과는 화면에 넣기
  전에 정화해 `<script>`와 이벤트 속성(`onclick` 등), `javascript:` 링크를 제거한다
  (D-6).
* 판정 방법:
  * 앱을 켜고 문서를 여닫고 끈 뒤 루트 안 모든 파일의 내용 해시와 수정 시각이 실행
    전과 같은지 확인한다.
  * `<script>`·`onerror` 속성·`javascript:` 링크를 담은 시험 문서를 열어 셋 다
    실행되지 않고 제거된 상태로 표시되는지 확인한다.

## 2. 비기능 요구사항

### NFR-1. 빠르게 뜨고 빠르게 그린다

* 내용: 앱 실행부터 탐색기가 보일 때까지 3초 이내, 1MB 마크다운 문서를 골라 화면에
  렌더링될 때까지 1초 이내다(로컬 SSD 기준).
* 판정 방법: 두 구간의 시각을 로그로 남겨 다섯 번 측정한 중앙값이 기준 이내인지
  확인한다.

### NFR-2. 고른 파일 하나만 읽는다

* 내용: 폴더를 열거나 트리를 펼치는 동안 문서·이미지 파일의 내용을 읽지 않는다.
  미리 읽기와 썸네일 생성을 하지 않는다.
* 판정 방법: 트리를 펼치는 동안 도메인 읽기 호출 횟수가 0건인지 확인한다.

### NFR-3. 빌드 단계가 없다

* 내용: 저장소에 번들러·트랜스파일러 단계를 두지 않는다. 반입한 라이브러리는 빌드
  없이 그대로 로드되는 배포본이며 버전이 고정돼 있다(D-5).
* 판정 방법: 저장소에 빌드 산출물을 만드는 단계가 0건인지, `vendor/` 아래 파일의
  버전이 문서에 적힌 값과 같은지 확인한다.

### NFR-4. 껍데기를 고치지 않는다

* 내용: `shell/`과 `shared/design/` 아래의 템플릿 파일을 수정하지 않는다. 앱 코드는
  프리셋과 보기, 그리고 갈래의 도메인 계층에만 있다.
* 판정 방법: 템플릿 원본과 대조해 `shell/` · `shared/design/`의 변경 줄 수가 0인지
  확인한다.

### NFR-5. 인터넷 없이 동작한다

* 내용: 문서 열람의 모든 기능이 네트워크 없이 동작한다. 외부 URL을 기본 브라우저로
  넘기는 것만 예외다.
* 판정 방법: 네트워크를 끊은 상태에서 FR-3 · FR-5 · FR-7 · FR-8의 판정을 전건
  통과하는지 확인한다.

### NFR-6. 오류가 앱을 멈추지 않는다

* 내용: 읽기 실패·경계 이탈·지원하지 않는 대상은 껍데기의 오류 계약(`ROOT_ESCAPE` ·
  `NOT_FOUND` · `PERMISSION_DENIED` · `READ_FAILED` · `USER_CANCELLED` ·
  `UNSUPPORTED_TARGET`) 코드로 돌려주고 화면에 알린다.
* 판정 방법: 각 오류를 유발하는 시험에서 해당 코드가 돌아오고, 앱이 종료되거나 다른
  탭이 영향을 받지 않는지 확인한다.

## 3. 제약사항

1. **운영체제** — Windows 10 이상 로컬 실행이 1차 대상이다.
2. **갈래** — Electron 갈래만 유지한다(D-3). `host_pywebview/`는 저장소에 두지 않는다.
3. **껍데기** — `tab-explorer-templates` v0.1을 복사해 쓰고 수정하지 않는다(D-2, NFR-4).
   앱이 쓰는 확장 지점은 갈아끼우는 자리 다섯과 보기 수명주기다.
4. **연결 계층** — 파일 읽기 등 호스트 동작은 브릿지 계약의 `call_domain`을 거친다.
   껍데기가 요구하지 않는 호스트 전용 동작을 새로 만들지 않는다.
5. **빌드 없음** — 번들러·트랜스파일러·프레임워크를 도입하지 않는다(NFR-3).
6. **의존성** — 마크다운 렌더러와 문법 강조기는 저장소에 반입한 고정 버전만 쓴다.
   실행 시점에 네트워크에서 내려받지 않는다(D-5).
7. **읽기 전용** — 파일을 쓰거나 지우거나 이름을 바꾸는 호출을 두지 않는다.

## 4. 미구현 대상

이번 버전에서 하지 않는 것. `BRIEF.md` 3절이 범위를 말하고 여기는 항목을 말한다.

1. **이미지 단독 보기** — 이미지 파일을 트리에 표시하거나 탭 하나로 여는 기능을 만들지
   않는다. 이미지는 마크다운 문서 안에서 참조될 때만 표시한다(FR-8).
2. **Jupyter Notebook 보기** — `.ipynb`를 표시하거나 여는 기능을 만들지 않는다.
3. **Mermaid · 수식(KaTeX) · Obsidian Wiki Link · 문서 전문 검색** — 넣지 않는다.
4. **자동 파일 감시** — 외부 변경을 감시해 자동 반영하지 않는다. 껍데기의 새로 읽기로만
   갱신한다.
5. **열린 탭 복원** — 다시 켰을 때 마지막에 열려 있던 문서 목록을 되살리지 않는다.
6. **편집 기능** — 문서 수정·생성·삭제·이름 변경을 넣지 않는다.
